# License and redistribution checklist

This repository intentionally does not include a top-level software `LICENSE` yet.

Before publishing, review at least:

1. **NTU RGB+D 60 / pre-extracted keypoints**: do not redistribute the dataset, derived data files, or checkpoints unless the dataset's current license/permission clearly allows it.
2. **Ultralytics YOLO Pose**: read the current AGPL-3.0 and Enterprise licensing terms; choose a project license only after confirming compatibility with your intended publication/deployment.
3. **Python dependencies**: keep third-party code and weights under their own applicable licenses.
4. **Privacy**: do not commit camera recordings containing identifiable people without a lawful basis and consent.

A README statement is not a substitute for legal authorization. This note is a project checklist, not legal advice.
